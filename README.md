### 1.6 分析问题（请逐条回答）

**Q1：Adam 和 SGD 的收敛速度有何差异？从实验结果中你观察到了什么？**

答：Adam/AdamW 在本任务中收敛更快，前期 loss 下降明显；SGD 对学习率更敏感，往往需要更长训练周期与更细致调参。

**Q2：学习率对训练稳定性有什么影响？**

答：学习率过大会造成验证集波动甚至错过最优点；过小则收敛过慢。`OneCycleLR` 能兼顾前期快速收敛和后期稳定细化。

**Q3：Batch Size 对模型泛化能力有什么影响？**

答：较大 batch 提升吞吐、训练更稳定，但随机性降低；需结合增强与正则化。实验中 `Batch Size=256` 结合增强/Dropout/早停，泛化表现依旧稳定。

**Q4：Early Stopping 是否有效防止了过拟合？**

答：有效。可在验证指标不再提升时提前停止，减少过拟合和无效训练时间，并保留最佳权重。

**Q5：数据增强是否提升了模型的泛化能力？为什么？**

答：是。手写数字存在旋转、平移、粗细等变化，增强让模型在训练中见到更多形态，从而提升鲁棒性与线上泛化效果。
